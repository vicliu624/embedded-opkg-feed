# 发布检查清单

[中文（当前）](RELEASE.zh-CN.md) | [English](RELEASE.md)

每次公开发布前，请按顺序完成以下检查。这里的目标不是尽快生成下载文件，而是确保设备只能看到已经验证、已签名且与其固件匹配的内容。

1. 选择一个已经声明的平台，并使用它锁定的 SDK/容器构建；绝不能使用宿主机自带的 RISC-V 软件包代替。
2. 确认每个包都使用所选平台的架构和精确 ABI 标记依赖。
3. 确认安装载荷没有进入受保护的固件目录。
4. 生成 `Packages` 和可复现的 `Packages.gz`。
5. 验证索引哈希和包控制元数据。
6. 在受保护的签名主机上对 `Packages.gz` 签名。
7. 使用已提交的公开密钥验证分离式签名。
8. 将不可变的软件源内容暂存到 `site/feed/<PLATFORM_ID>/riscv64/` 下。
9. 将生成的公开文件提交到受保护的 `release` 分支。
10. 只有签名验证成功后，才允许 Pages 工作流发布。
11. 在非生产 K230 上测试：正确安装、拒绝错误签名、拒绝错误 ABI、卸载以及回滚；全部通过后再批准发布。

签名细节见 [签名与发布安全策略](SIGNING.zh-CN.md)，平台兼容性细节见 [平台兼容性约定](PLATFORM.zh-CN.md)。
