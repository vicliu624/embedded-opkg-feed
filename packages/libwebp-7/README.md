# WebP runtime provider

This feed-only library is built from the SHA256-locked WebP 1.5.0 source with
the ABI-matched CPU0 package SDK. The platform image and SDK remain unchanged.

The package owns `libwebp.so.7`, `libwebpdemux.so.2`, `libwebpmux.so.3` and
`libsharpyuv.so.0`. All four are generated by the same upstream source build.
The SharpYUV library is required by the main WebP library and must be included.
Headers, linker links and pkg-config files are exported to private development
staging for consumers; the runtime package contains shared libraries only.

`build-all.sh` registers the produced SONAMEs after package validation and
exports their package/version identities alongside development staging.
A later batch can import that staging and supply the matching WebP IPK with
`--provided-package libwebp-7`, avoiding another WebP source build.

The generated libtool configuration avoids install-time relinking against host
library paths. The SDK's unsafe-path guard stays enabled, and runtime search
paths are checked and removed by the existing payload policy.
